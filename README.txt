# Weather AI Assistant

Телеграм-бот, который запрашивает GPS-координаты пользователя, получает прогноз погоды и пересказывает его простым живым языком с помощью локальной нейросети.

## Как устроен проект
* Код разделен на два файла: `assistant.py` (работа с данными и ИИ) и `bot.py` (интерфейс Телеграма).
* Перед отправкой в ИИ данные фильтруются через Pandas — числа осадков переводятся в слова, чтобы модель не путалась в цифрах.
* Для генерации текста используется локальная модель Qwen 2.5 (7B) через Ollama.
* Токен бота скрыт в файле `.env` и добавлен в `.gitignore`.

## Что нужно для запуска
1. Скачать и запустить Ollama с моделью `qwen2.5:7b`.
2. Установить библиотеки: `pip install pandas requests pyTelegramBotAPI python-dotenv ollama`.
3. Создать файл `.env` и написать туда: `BOT_TOKEN=твой_токен`.
4. Запустить файл: `python bot.py`.
